Add "class settings" so a teacher can practise with a class like theirs. Read this whole message first, then do Parts A → D in order.

## The rule that matters most

A setting describes the room's CONDITIONS, never the kids:
- **The conditions are:** class size, who is in the class (mixed, boys or girls), the language mix, and exam focus.
- **Never the kids' ability**, intelligence, manners or background.
- **Every behaviour change below comes from one of those four conditions** and nothing else.
- **Never write anything like "public-school kids are…"** in code, prompts, copy or comments.
- **Show this line wherever settings are chosen:** "الإعدادات بتغيّر ظروف الصف، مش قدرات الطلاب. / Settings change the room, not the kids' abilities."

## Guardrails

- **The default setting must behave EXACTLY like today:**
  - the same names, voices, clips, rules and score;

  - stage mode (`?demo=1`) always uses the default setting, read-only;

## PART A: the setting and where the teacher picks it

1. **`shared/setting.ts`:**

   ```
   ClassSetting = { preset: 'private_mixed' | 'public_boys' | 'public_girls' | 'custom',
                    size: number (15–45), group: 'mixed' | 'boys' | 'girls',
                    langMix: 'arabic' | 'mixed_english', examFocus: 'normal' | 'high' }
   ```

   The presets' labels only describe conditions:

   | Preset | Label | size | group | langMix | examFocus |
   |---|---|---|---|---|---|
   | `private_mixed` (DEFAULT, today's behaviour) | "خاصة · مختلط · 24 طالب" / "Private · mixed · 24 students" | 24 | mixed | arabic | normal |
   | `public_boys` | "حكومية · ذكور · 42 طالب" / "Public · boys · 42 students" | 42 | boys | arabic | normal |
   | `public_girls` | "حكومية · إناث · 38 طالب" / "Public · girls · 38 students" | 38 | girls | arabic | normal |
   | `custom` | any combination | | | | |

   `large` = size ≥ 35.
2. **Plan page, "Your class today" strip:**
   - Header line: "صفّك اليوم: {label} · غيّر / Your class today: {label} · Change".
   - "Change" opens a small panel with:
     - the 3 presets as pills;
     - custom fields: class size (a slider, 15–45); class (mixed, boys or girls); a "Kids mix English words into Arabic" switch (Arabic lessons only); an "Exam focus: high" switch;
     - the conditions-not-abilities line.
   - The strip updates names and portraits at once.
   - Remember the last choice in localStorage (inside try/catch).
   - In stage mode the strip is read-only and always shows the default.
3. **Saving the setting:**
   - Lessons get a nullable `setting_json`.
   - POST /api/lessons accepts `setting`; if it's missing, use the default.
   - The review header shows the setting label after the topic.
   - "Teach it again" and "Edit plan and teach again" keep the setting.

## PART C: what the conditions change in behaviour

- **All dials live in `shared/setting.ts` as data**, so they're testable.
- **Prompts get a short CLASS CONDITIONS note only for non-default settings.** Default prompts stay byte-identical.

1. **Large class (size ≥ 35):**
   - **"Back of the class" strip:** a slim ink/grey strip above the class row.
     - Label: "آخر الصف · {size} طالب / Back of the class · {size} students".
     - Level 0–3: هادي، في همس، بدأ يتلهّى، صاير في حكي / quiet, murmuring, drifting, chatty.
     - The code rules, per teacher turn:
       - +1 if the teacher talked for more than 30 s, or if this is the 2nd turn in a row with no real question;
       - −1 if the turn has a real question to the whole class (check = "question" and no kid named);
       - clamp the level to 0–3.
     - At level 2 and above, play a soft murmur, synthesised in sfx.ts, under the voices and off in Calm mode.
     - No status colours, and no score.
   - **The chorus:** add 3 extra, quieter copies (gain 0.3, extra delays of 60–320 ms) so it sounds like a big class.
   - **Raised hands:** about one every 3rd turn instead of every 2nd, since 40-plus kids share one teacher.
   - **The review:** one line, shown and not scored: "آخر الصف: بدأ يتلهّى بالمداخلات 3–4 / Back of the class: drifted in turns 3–4", or "stayed with you".
   - **The scorer:** pass the class conditions, so one_tip and try_saying fit a large class. For example, everyone answers at once: fingers up, mini whiteboards, or "tell your neighbour, then I'll pick". The score numbers don't change.
2. **Language mix `mixed_english`** (Arabic lessons only):
   - Kid lines may mix in English school words, the way bilingual kids do: "Miss، بس ليش الـdenominator أكبر؟".
   - Add those English words to the STT prompt sentence.
   - Captions show exactly what's said.
3. **Exam focus `high`:**
   - The relevance kid (the khaled role) asks about the exam instead of real life: "هاد بيجي بالامتحان؟" / "Is this in the exam?".
   - The rule-memoriser (the sara role) asks for the rule to memorise: "طيب شو القاعدة اللي بنحفظها؟" / "So what's the rule we memorise?".
   - Their misconceptions, helped_if and hurt_if don't change. Answering "yes, it's in the exam" still doesn't reach the relevance kid, because hurt_if already covers it; the teacher still needs a real example or the reason.
4. **Group (boys or girls)** changes names, voices, grammar and portraits only. It never changes behaviour.
